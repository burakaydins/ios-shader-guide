# Ready-made recipes (SwiftUI + MSL)

> This file is generated by `tools/build_recipes.py`. Code blocks are copied from `examples/ShaderLab/Shaders.metal`; to change code, edit that file and do not edit this file by hand.

All iOS 17+ / macOS 14+. Compile and try the code in Xcode: the environment where these recipes were written had no Metal compiler, and they only passed a rough syntax check (`tools/syntax_check.py`). If you could not compile, tell the user so.

Shared header (top of every `.metal` file):


The Swift examples use `AnimatedShader { t in ... }`; it is defined in `swift-patterns.md` section 1.

## Type choice and `maxSampleOffset` summary

| Recipe | What it reads | `maxSampleOffset` |
|---|---|---|
| wave | vertical shift based on horizontal position | `CGSize(width: 0, height: amplitude)` |
| swirl | position rotated around the center | `CGSize(width: 2 * radius, height: 2 * radius)` (a rotation moves a point by at most the diameter) |
| chromaticAberration | ±amount horizontally | `CGSize(width: amount, height: 0)` |
| pixelate | the cell center | `CGSize(width: cell, height: cell)` |
| ripple | up to `amount` in the direction | `CGSize(width: amplitude, height: amplitude)` |
| lens | toward the center | `CGSize(width: radius, height: radius)` |
| glitch | horizontal shift + 2 | `CGSize(width: intensity + 2, height: 0)` |
| glow | ring radius | `CGSize(width: radius, height: radius)`; also give the view `.padding(radius)` (see below) |

`colorEffect` does not read other positions; it has no `maxSampleOffset`.

## 1. plasma: animated plasma (colorEffect)

The sum of three sine waves, color from a cosine palette. Fast, cheap, looks good on any screen.

```metal
[[ stitchable ]] half4 plasma(float2 position, half4 color, float2 size, float time) {
    float2 uv = position / size;
    float v = sin(uv.x * 10.0f + time)
            + sin(uv.y * 10.0f + time * 1.3f)
            + sin((uv.x + uv.y) * 10.0f + time * 0.7f);
    float3 col = palette(v / 3.0f);
    return half4(half3(col), 1.0h) * color.a;
}
```

```swift
AnimatedShader { t in
    Rectangle()
        .visualEffect { content, proxy in
            content.colorEffect(ShaderLibrary.plasma(.float2(proxy.size), .float(t)))
        }
}
.ignoresSafeArea()
```

Parameters: `size` is the view size in points, `time` is in seconds. The `10.0` coefficient sets how many waves there are; raise it and the pattern gets denser. The waves produce a smooth gradient; if you see banding, see the `dithersColor` note in `swiftui-shaders.md` section 10.

## 2. aurora: fluid, organic background (colorEffect)

`fbm` (multi-layer noise) and domain warping. The starting point for "fluid", "liquid", "aurora", "lava lamp" requests.

```metal
[[ stitchable ]] half4 aurora(float2 position, half4 color, float2 size, float time) {
    float2 p = position / size.y * 2.0f;
    float t = time * 0.15f;
    // domain warping: use noise to bend the coordinates of more noise
    float2 q = float2(fbm(p + t), fbm(p + float2(5.2f, 1.3f) - t));
    float n = fbm(p + 2.0f * q + t * 0.5f);
    float3 col = mix(float3(0.02f, 0.05f, 0.15f), float3(0.10f, 0.90f, 0.60f), smoothstep(0.2f, 0.8f, n));
    col = mix(col, float3(0.60f, 0.30f, 0.90f), smoothstep(0.5f, 1.0f, q.x * q.y * 2.0f));
    return half4(half3(col), 1.0h) * color.a;
}
```

```swift
AnimatedShader(fps: 30) { t in
    Rectangle()
        .visualEffect { content, proxy in
            content.colorEffect(ShaderLibrary.aurora(.float2(proxy.size), .float(t)))
        }
}
.ignoresSafeArea()
```

It is expensive: 3 `fbm` per pixel, each with 5 octaves. Do not promise 60 fps full screen without measuring on a real device; `fps: 30` is a reasonable start. You can reduce the octave count in the `fbm` loop in `ShaderHelpers.h`.

## 3. vignette: edge darkening (colorEffect)

```metal
[[ stitchable ]] half4 vignette(float2 position, half4 color, float2 size, float strength) {
    float2 uv = position / size - 0.5f;
    float v = 1.0f - smoothstep(0.2f, 0.8f, length(uv));   // 1 in the center, 0 at the corners
    half k = half(mix(1.0f, v, strength));
    return half4(color.rgb * k, color.a);
}
```

```swift
content.visualEffect { c, proxy in
    c.colorEffect(ShaderLibrary.vignette(.float2(proxy.size), .float(0.8)))
}
```

`strength` ranges from 0 (no effect) to 1 (edges fully black). Do not write `smoothstep` edges reversed: `smoothstep(0.8, 0.2, x)` gives unreliable results; if you want the inverse, write `1.0 - smoothstep(low, high, x)` (the recipe does it this way).

## 4. shimmer: shine band (colorEffect)

A light band passing from left to right over text or a card.

```metal
[[ stitchable ]] half4 shimmer(float2 position, half4 color, float2 size, float time, float width) {
    float x = position.x / size.x;
    float center = fract(time * 0.4f) * 1.4f - 0.2f;          // sweeps from -0.2 to 1.2
    float band = 1.0f - smoothstep(0.0f, width, abs(x - center));
    return half4(color.rgb + half3(half(band)) * color.a, color.a);
}
```

```swift
AnimatedShader { t in
    Text("Premium")
        .font(.largeTitle.bold())
        .visualEffect { c, proxy in
            c.colorEffect(ShaderLibrary.shimmer(.float2(proxy.size), .float(t), .float(0.15)))
        }
}
```

`width` is 0–1, a fraction of the view width. Multiplying by `color.a` stops transparent pixels (outside the text) from lighting up.

## 5. duotone: two-color photo (colorEffect)

Converts the image to luminance and paints shadows and highlights with the two colors you choose.

```metal
[[ stitchable ]] half4 duotone(float2 position, half4 color, half4 shadow, half4 highlight) {
    half3 rgb = unpremultiply(color);
    half lum = dot(rgb, half3(0.299h, 0.587h, 0.114h));
    half3 mapped = mix(shadow.rgb, highlight.rgb, lum);
    return half4(mapped * color.a, color.a);
}
```

```swift
Image("photo")
    .resizable().scaledToFit()
    .colorEffect(ShaderLibrary.duotone(.color(.indigo), .color(.yellow)))
```

`.color(...)` goes to the shader as a premultiplied `half4` (Apple's `Shader.Argument.color` description). There is no difference for opaque colors; account for it if you pass a translucent color. The incoming `color` is premultiplied too, so the recipe first separates alpha with `unpremultiply`.

## 6. filmGrain: film grain (colorEffect)

```metal
[[ stitchable ]] half4 filmGrain(float2 position, half4 color, float time, float intensity) {
    float n = hash21(position + floor(time * 24.0f) * 17.0f);   // new grain 24 times a second
    half g = half((n - 0.5f) * intensity);
    return half4(color.rgb + g * color.a, color.a);
}
```

```swift
AnimatedShader(fps: 24) { t in
    content.colorEffect(ShaderLibrary.filmGrain(.float(t), .float(0.12)))
}
```

An `intensity` of 0.05–0.2 is reasonable. The grain changes 24 times a second (`floor(time * 24)`); matching it with `AnimatedShader(fps: 24)` avoids drawing needless frames.

## 7. scanlines: CRT scan lines (colorEffect)

```metal
[[ stitchable ]] half4 scanlines(float2 position, half4 color, float spacing, float strength) {
    float line = 0.5f + 0.5f * sin(position.y * TAU / spacing);
    half k = half(1.0f - strength * line);
    return half4(color.rgb * k, color.a);
}
```

```swift
content.colorEffect(ShaderLibrary.scanlines(.float(3), .float(0.25)))
```

`spacing` is in points (3 = a line every 3 points). Very dense values (1–2) can cause moiré on a Retina screen.

## 8. holo: holographic card shine (colorEffect)

A rainbow reflection and glitter specks; it shifts with `tilt` (−1…1). Can be driven by dragging the card or tilting the device (CoreMotion, see `swift-patterns.md` section 5).

```metal
[[ stitchable ]] half4 holo(float2 position, half4 color, float2 size, float2 tilt) {
    float2 uv = position / size;
    float t = (uv.x + uv.y) * 1.5f + tilt.x * 1.2f + tilt.y * 0.6f;
    half3 rainbow = half3(palette(t));
    float grain = step(0.985f, hash21(floor(position / 3.0f)));      // glitter specks
    float glint = grain * (0.5f + 0.5f * sin(tilt.x * 6.0f + uv.x * 20.0f));
    half3 sheen = rainbow * 0.30h + half3(half(glint));
    return half4(color.rgb + sheen * color.a, color.a);
}
```

```swift
@State private var tilt = CGSize.zero

card
    .visualEffect { c, proxy in
        c.colorEffect(ShaderLibrary.holo(.float2(proxy.size), .float2(tilt.width, tilt.height)))
    }
    .gesture(DragGesture(minimumDistance: 0)
        .onChanged { v in tilt = CGSize(width: max(-1, min(1, v.translation.width / 100)),
                                        height: max(-1, min(1, v.translation.height / 100))) }
        .onEnded { _ in withAnimation(.spring) { tilt = .zero } })
```

## 9. dissolve: dissolve with noise (colorEffect)

As `progress` goes 0 → 1 the view disappears piece by piece along a noise pattern, with a burning strip in the `rim` color at the edge. Use as a transition is in `swift-patterns.md` section 6.

```metal
// progress 0 = fully visible, 1 = fully gone. `rim` is a premultiplied color
// (Swift: .color(.orange)) used for the burning edge.
[[ stitchable ]] half4 dissolve(float2 position, half4 color, float2 size,
                                float progress, float scale, half4 rim) {
    float n = fbm(position / size.y * scale);
    float thr = mix(-0.1f, 1.05f, progress);
    float keep = smoothstep(thr, thr + 0.06f, n);
    float edge = smoothstep(thr - 0.01f, thr + 0.02f, n)
               * (1.0f - smoothstep(thr + 0.02f, thr + 0.07f, n));
    half4 base = color * half(keep);
    half4 burn = rim * half(edge) * color.a;
    return min(base + burn, half4(1.0h));
}
```

```swift
content.visualEffect { c, proxy in
    c.colorEffect(ShaderLibrary.dissolve(.float2(proxy.size), .float(progress), .float(6), .color(.orange)))
}
```

`scale` is the noise frequency (6 = roughly a 6-blotch pattern across the view height).

## 10. textGradient: painting text with a shader (ShapeStyle)

A shader can be used as a `ShapeStyle`. In that case the signature has no `color`: `half4 f(float2 position, args...)`. The `.boundingRect` argument supplies the text's own bounds.

```metal
// Used as a ShapeStyle (Text.foregroundStyle / Shape.fill). Note the signature:
// no `color` parameter. `bounds` is `.boundingRect` = float4(x, y, width, height).
[[ stitchable ]] half4 textGradient(float2 position, float4 bounds, float time) {
    float2 uv = (position - bounds.xy) / bounds.zw;
    float3 col = palette(uv.x * 0.8f + uv.y * 0.3f + time * 0.2f);
    return half4(half3(col), 1.0h);
}
```

```swift
AnimatedShader { t in
    Text("Shader")
        .font(.system(size: 64, weight: .heavy))
        .foregroundStyle(ShaderLibrary.textGradient(.boundingRect, .float(t)))
}
```

Apple documents that `Shader` is a `ShapeStyle` and expects this signature. Against banding there is the `Shader.dithersColor` property (see `swiftui-shaders.md` section 10).

## 11. metaballs: sticky blobs (colorEffect, generator)

Circles that approach each other merge via `smin` (smooth minimum). It ignores the input color and produces its own shape; areas left transparent show the view behind.

```metal
[[ stitchable ]] half4 metaballs(float2 position, half4 color, float2 size, float time, half4 tint) {
    float2 p = centeredUV(position, size);
    float d = 10.0f;
    for (int i = 0; i < 5; i++) {
        float fi = float(i);
        float2 c = 0.28f * float2(sin(time * (0.50f + 0.13f * fi) + fi * 2.1f),
                                  cos(time * (0.40f + 0.11f * fi) + fi * 1.7f));
        d = smin(d, sdCircle(p - c, 0.09f + 0.015f * fi), 0.12f);
    }
    float aa = 1.5f / size.y;                          // about one and a half points, in uv units
    float shape = 1.0f - smoothstep(-aa, aa, d);
    return tint * half(shape);                         // tint is premultiplied
}
```

```swift
AnimatedShader { t in
    Rectangle().fill(.black)
        .visualEffect { c, proxy in
            c.colorEffect(ShaderLibrary.metaballs(.float2(proxy.size), .float(t), .color(.cyan)))
        }
}
```

## 12. voronoiCells: cellular pattern (colorEffect)

```metal
[[ stitchable ]] half4 voronoiCells(float2 position, half4 color, float2 size, float time) {
    float2 p = position / size.y * 6.0f;
    p += 0.25f * float2(sin(time * 0.4f), cos(time * 0.3f));
    float2 d = voronoi(p);
    float edge = smoothstep(0.0f, 0.06f, d.y - d.x);   // 0 on cell borders
    float3 col = palette(d.x * 0.8f + time * 0.05f) * (0.35f + 0.65f * edge);
    return half4(half3(col), 1.0h);
}
```

```swift
AnimatedShader(fps: 30) { t in
    Rectangle()
        .visualEffect { c, proxy in
            c.colorEffect(ShaderLibrary.voronoiCells(.float2(proxy.size), .float(t)))
        }
}
```

It scans 9 cells per pixel. Adjust the cell count with the `6.0` multiplier.

## 13. sphereMarch: a 3D sphere via raymarching (colorEffect)

It draws an SDF by stepping rays. The loop is kept constant and small (48 steps); this technique is expensive full screen.

```metal
static inline float sceneSDF(float3 p, float time) {
    float r = 1.0f + 0.12f * sin(time * 2.0f + p.y * 3.0f);   // wobbling sphere
    return length(p) - r;
}

[[ stitchable ]] half4 sphereMarch(float2 position, half4 color, float2 size, float time) {
    float2 p = centeredUV(position, size);
    p.y = -p.y;                                    // 3D wants y up
    float3 ro = float3(0.0f, 0.0f, -3.0f);         // ray origin (camera)
    float3 rd = normalize(float3(p, 1.6f));        // ray direction
    float t = 0.0f;
    bool hit = false;
    for (int i = 0; i < 48; i++) {                 // fixed, small step budget
        float d = sceneSDF(ro + rd * t, time);
        if (d < 0.002f) { hit = true; break; }
        t += d;
        if (t > 8.0f) { break; }
    }
    float3 bg = mix(float3(0.05f, 0.06f, 0.12f), float3(0.15f, 0.12f, 0.25f), position.y / size.y);
    if (!hit) { return half4(half3(bg), 1.0h); }

    float3 pos = ro + rd * t;
    float2 e = float2(0.002f, 0.0f);
    float3 n = normalize(float3(
        sceneSDF(pos + e.xyy, time) - sceneSDF(pos - e.xyy, time),
        sceneSDF(pos + e.yxy, time) - sceneSDF(pos - e.yxy, time),
        sceneSDF(pos + e.yyx, time) - sceneSDF(pos - e.yyx, time)));
    float3 lightDir = normalize(float3(0.6f, 0.8f, -0.5f));
    float diff = max(dot(n, lightDir), 0.0f);
    float rim = pow(1.0f - max(dot(n, -rd), 0.0f), 3.0f);
    float3 col = palette(0.55f + 0.2f * n.y + 0.1f * time) * (0.15f + 0.85f * diff) + rim * 0.4f;
    return half4(half3(col), 1.0h);
}
```

```swift
AnimatedShader(fps: 30) { t in
    Rectangle()
        .visualEffect { c, proxy in
            c.colorEffect(ShaderLibrary.sphereMarch(.float2(proxy.size), .float(t)))
        }
        .frame(width: 300, height: 300)       // start on a small area
}
```

The normal is computed by the gradient method (neighboring SDF samples). To grow the scene, add other shapes into `sceneSDF` with `min` (see `advanced-techniques.md`).

## 14. chromaticAberration: color channel split (layerEffect)

```metal
[[ stitchable ]] half4 chromaticAberration(float2 position, SwiftUI::Layer layer, float amount) {
    half4 r = layer.sample(position + float2(amount, 0.0f));
    half4 g = layer.sample(position);
    half4 b = layer.sample(position - float2(amount, 0.0f));
    return half4(r.r, g.g, b.b, max(r.a, max(g.a, b.a)));
}
```

```swift
view.layerEffect(
    ShaderLibrary.chromaticAberration(.float(4)),
    maxSampleOffset: CGSize(width: 4, height: 0)
)
```

`amount` is in points; animate it larger and it becomes an impact/damage effect.

## 16. ripple: touch ripple (layerEffect)

A decaying wave that spreads outward from the touched point. The wavefront reaches each pixel `distance / speed` seconds later.

```metal
[[ stitchable ]] half4 ripple(float2 position, SwiftUI::Layer layer, float2 origin, float time,
                              float amplitude, float frequency, float decay, float speed) {
    float2 d = position - origin;
    float dist = length(d);
    float2 dir = dist > 0.001f ? d / dist : float2(0.0f);       // guard: normalize(0) is NaN
    float t = max(0.0f, time - dist / speed);                   // the wave front reaches this pixel at dist/speed
    float amount = amplitude * sin(frequency * t) * exp(-decay * t);
    half4 c = layer.sample(position + dir * amount);
    c.rgb += c.a * half(0.3f * amount / max(amplitude, 0.0001f));   // light crest, dark trough
    return c;
}
```

The Swift side is a full example in `swift-patterns.md` section 3. Parameter units: `amplitude` points (e.g. 14), `frequency` radians/second (e.g. 18), `decay` 1/second (e.g. 5), `speed` points/second (e.g. 900). `maxSampleOffset` = `amplitude`.

## 17. lens: magnifier (layerEffect)

```metal
[[ stitchable ]] half4 lens(float2 position, SwiftUI::Layer layer, float2 center, float radius, float strength) {
    float2 d = position - center;
    float r = length(d);
    float k = smoothstep(0.0f, radius, r);               // 0 in the middle, 1 at the rim
    float scale = mix(1.0f - strength, 1.0f, k);         // below 1 reads from nearer the center = magnify
    float2 src = r < radius ? center + d * scale : position;
    half4 c = layer.sample(src);
    float rim = smoothstep(radius - 2.0f, radius, r) * (1.0f - smoothstep(radius, radius + 1.5f, r));
    c.rgb += c.a * half(rim * 0.3f);
    return c;
}
```

```swift
view.layerEffect(
    ShaderLibrary.lens(.float2(touch), .float(80), .float(0.5)),
    maxSampleOffset: CGSize(width: 80, height: 80)
)
```

`strength` is 0–1: 0.5 magnifies 2x at the center. For `touch` see `swift-patterns.md` section 2.

## 18. glitch: signal corruption (layerEffect)

```metal
[[ stitchable ]] half4 glitch(float2 position, SwiftUI::Layer layer, float time, float intensity) {
    float slice = floor(position.y / 10.0f);
    float tick = floor(time * 12.0f);
    float gate = step(0.92f, hash21(float2(slice, tick)));                       // ~8% of slices tear
    float shift = (hash21(float2(slice + 17.0f, tick)) - 0.5f) * 2.0f * intensity * gate;
    half4 r = layer.sample(position + float2(shift + 2.0f * gate, 0.0f));
    half4 g = layer.sample(position + float2(shift, 0.0f));
    half4 b = layer.sample(position + float2(shift - 2.0f * gate, 0.0f));
    return half4(r.r, g.g, b.b, max(r.a, max(g.a, b.a)));
}
```

```swift
AnimatedShader { t in
    view.layerEffect(
        ShaderLibrary.glitch(.float(t), .float(18)),
        maxSampleOffset: CGSize(width: 18 + 2, height: 0)
    )
}
```

Horizontal bands (10 points tall) shift randomly and the channels separate. `intensity` is the maximum horizontal shift (points). Triggering it as a short-lived "fault" (e.g. 0.3 s) is more effective than running it continuously.

## 19. glow: outer glow (layerEffect)

It samples the alpha of surrounding pixels to produce a halo.

```metal
// glowColor is premultiplied (that is how Shader.Argument.color is delivered).
[[ stitchable ]] half4 glow(float2 position, SwiftUI::Layer layer, half4 glowColor, float radius) {
    half4 base = layer.sample(position);
    half acc = 0.0h;
    const int rings = 2;
    const int taps = 12;
    for (int ring = 1; ring <= rings; ring++) {
        float rr = radius * float(ring) / float(rings);
        for (int i = 0; i < taps; i++) {
            float a = TAU * float(i) / float(taps);
            acc += layer.sample(position + rr * float2(cos(a), sin(a))).a;
        }
    }
    acc /= half(rings * taps);
    half4 halo = glowColor * acc;
    return base + halo * (1.0h - base.a);              // halo only where the view itself is not opaque
}
```

```swift
Image(systemName: "bolt.fill")
    .font(.system(size: 80))
    .padding(24)                                   // make room for the glow: assume the effect does not exceed the view bounds
    .layerEffect(
        ShaderLibrary.glow(.color(.yellow), .float(20)),
        maxSampleOffset: CGSize(width: 20, height: 20)
    )
```

Apple does not document whether the effect may spill outside the view bounds; the safe way is to give enough `.padding` for the glow. It takes 24 samples per pixel; use it on small views.

## 20. wave: rippling (distortionEffect)

```metal
[[ stitchable ]] float2 wave(float2 position, float time, float amplitude, float frequency) {
    position.y += sin(position.x * frequency + time) * amplitude;
    return position;
}
```

```swift
AnimatedShader { t in
    Image("photo")
        .resizable().scaledToFit()
        .distortionEffect(
            ShaderLibrary.wave(.float(t), .float(12), .float(0.05)),
            maxSampleOffset: CGSize(width: 0, height: 12)     // equal to amplitude
        )
}
```

`amplitude` (points) and `maxSampleOffset.height` must be equal. `frequency` is radians/point: because `position` is in points it is kept small (0.05 ≈ one wave per 125 points). For a flag-like wave pinned at one end, multiply `amplitude` by `position.x / size.x`.

## 21. swirl: whirlpool (distortionEffect)

```metal
[[ stitchable ]] float2 swirl(float2 position, float2 center, float radius, float angle) {
    float2 d = position - center;
    float r = length(d);
    if (r >= radius) { return position; }
    float t = 1.0f - r / radius;                 // 1 at the center, 0 at the rim
    float a = angle * t * t;
    return center + rotate2d(d, a);
}
```

```swift
view.distortionEffect(
    ShaderLibrary.swirl(.float2(touch), .float(120), .float(3)),
    maxSampleOffset: CGSize(width: 240, height: 240)           // 2 * radius
)
```

`angle` is in radians; the rotation is greatest at the center and 0 at the edge. Because a rotation can move a point by at most the diameter (2 × radius), `maxSampleOffset` is 2 × radius.

## When adding a new recipe

Every recipe should contain these five: which modifier type and why; the `maxSampleOffset` reasoning (for layer/distortion); the unit of every parameter (points, 0–1, radians); Swift usage; a cost note. Add the code to `Shaders.metal` first with `// <recipe:name>` markers, then run `python3 tools/build_recipes.py`.
